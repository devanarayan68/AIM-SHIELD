AI Pipeline — Step by Step
01
Data Collection
CPU, Memory, RPS, Latency, Logs collected every 2 seconds from infrastructure
02
TF-IDF Vectorization
Log text converted into numerical feature vectors — keywords like "error", "timeout", "overflow" get high weights
03
Isolation Forest
Detects anomalies in system metrics — data points deviating from normal baseline are flagged immediately
04
Logistic Regression
Classifies each log entry as Normal, Warning, or Critical using TF-IDF features
05
Random Forest
Combines all features — CPU trend, memory, RPS, anomaly score, log severity — to predict failure probability
06
Decision Engine
If failure probability > 70% → triggers self-healing. If > 45% → escalates monitoring and alerts
07
Self-Healing & Auto-Scale
New server provisioned via cloud API OR failed container restarted. Load balancer updated automatically
